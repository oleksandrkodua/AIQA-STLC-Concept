# Decisions

The log of decisions for this project. Empty on a fresh copy.

- `DECISIONS.md`: one row per decision: ID, decision, status, basis.
- `verification-log.md`: unverified claims the plan depends on, with a PASS and FAIL condition written before the check.
- `CONFLICTS.md`: conflicts between sources that cannot be resolved by the authority order in `context/sources.md` (format: `.claude/rules/ai-rules.md`, rule 6).
- Proposals that wait for approval: `PROPOSALS-<date>.md`, one section per proposal.

Rules: do not rewrite history; add a row that supersedes an old one. A decision has a status: STATED (the owner said it), PROPOSED (suggested by Claude, not confirmed), VERIFIED (checked against evidence).
