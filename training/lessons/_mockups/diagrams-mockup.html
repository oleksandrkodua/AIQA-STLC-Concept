What colour means on every diagram

  • ● green in use, confirmed, passed
  • ◐ amber draft, not run, pending, needs attention
  • ? red unverified, blocked, failed, hostile input
  • ○ dashed grey not used
  • plain structure only, no status
  • thick outline a human step or gate

Colour is never the only carrier: every state also has a word or a mark. Proposal, not approved.

Replaces the source infographic. Checked against Anthropic documentation on 2026-10-14. Not run on our machines.

Hooks

A separate command, outside the Claude Code process.

Claude CodeEventyour scriptAllow or block
  • Exit code 2 stops a tool call. Any other exit code does not.
  • Can add context or write a log.
  • Cannot draw in the UI (only mods can).
◐ OUR HOOKS: DRAFT, NOT ACTIVE◐ DOCS-CONFIRMED, NOT RUN HERE

Mods

A TypeScript function inside the process.

Claude CodeTypeScript function
  • Rewrite a prompt before the model sees it.
  • Hold or change a tool call.
  • Redraw parts of the UI, add /commands.

Slide mockups, lessons 0–13 and bonus B

The mapping for L0, L2, L7, L13 and bonus B had no single obvious term; it was proposed by the assistant and confirmed by the author on 2026-10-14.
